Pill action button with an uppercase Overpass Mono label — use for any primary or secondary call to action ("INSCRIÇÃO", "RESERVA GRÁTIS AQUI").

```jsx
<Button variant="primary">Inscrição</Button>
<Button variant="outline" size="lg">Reserva grátis aqui</Button>
```

Variants: `primary` (solid coral red), `deep` (solid bordô), `outline` (heavy red ring on transparent), `outline-light` (cream ring, for dark/footer backgrounds), `ghost`. Sizes: `sm` `md` `lg`. Pass `as="a"` + `href` for link buttons. Labels are auto-uppercased.
