Eyebrow + serif (Abhaya Libre) display title — the standard section opener.

```jsx
<SectionHeading eyebrow="Sobre">Em que consiste?</SectionHeading>
<SectionHeading eyebrow="Oradores" size="l" align="start">Quem são os oradores?</SectionHeading>
```

`size`: `m` (section), `l`, `xl` (hero). Use `color`/`eyebrowColor` on dark or band backgrounds.
