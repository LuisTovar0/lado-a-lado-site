# UI Kit — Merch Shop ("Loja")

A recreation of the Lado a Lado merch line as a shop collection, built from the slogan compositions on the Figma `Merch` page (coffee + apparel).

## Files
- `index.html` — entry; mounts `Merch`.
- `Merch.jsx` — shop page: nav, hero, product grid, bordô feature band, footer.

## Notes
Each product card is a typographic slogan composition on a brand colour with a merch `Icon` (Heart / Smile / Coffee / SmileyHappyPlus) — mirroring the file's "Made to love and be loved", "Requires caffeine & perseverance", "Fidelity advocate" pieces. Product cards lift on hover. Prices are representative placeholders.
